# Starter research

Replace this with the steps for the new playbook. `template.md` is the result. `## Steps` is the work, in the order a person would do it. Name every field whose `x-source` is `research`, and link the shared guide it uses.

## Steps

1. Ask for every `user` or `user_data` field the context does not already answer. Wait for the answer.
2. Research `background` from the guide linked below.
3. Fill `template.md` from those values. Label an estimate `Assumption:`.
4. List every page you opened in `sources`.

- `background`: use the sources that fit the topic, such as [market-size.md](../../research/market-size.md).
- `sources`: one entry per page you opened, with title, publisher, URL, and the date you opened it. If you could not browse, set `research_mode` to `offline`, leave `sources` empty, and label every researched field `Assumption:`.
